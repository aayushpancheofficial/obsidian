# Floating Point Representation

## Meaning

Floating point representation stores real numbers using mantissa and exponent.

```text
Number = Mantissa x Base^Exponent
```

## Fields

- Sign bit
- Exponent
- Mantissa

## Example

```text
1.25 x 10^3
```

Here, 1.25 is mantissa and 3 is exponent.

## Exam Answer

Floating point representation is used to store very large and very small real numbers. It uses sign, exponent, and mantissa fields.
