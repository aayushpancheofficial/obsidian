# Peripheral Devices

## Definition

Peripheral devices are external devices connected to a computer for input, output, storage, or communication.

## Types

| Type | Examples |
|---|---|
| Input | Keyboard, mouse, scanner |
| Output | Monitor, printer, speaker |
| Storage | HDD, SSD, pen drive |
| Communication | Modem, network card |

## Exam Answer

Peripheral devices extend computer functionality by allowing users to input data, receive output, store information, and communicate with other systems.
