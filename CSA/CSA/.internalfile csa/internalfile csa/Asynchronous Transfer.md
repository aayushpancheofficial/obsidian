# Asynchronous Transfer

## Definition

Asynchronous transfer does not use a common clock. It uses handshaking signals.

## Handshaking

```text
Sender: Data valid
Receiver: Data accepted
```

## Features

- Flexible.
- Suitable for devices with different speeds.
- Slower due to control signals.

## Exam Answer

Asynchronous transfer uses request and acknowledge signals to coordinate data transfer without a common clock.
