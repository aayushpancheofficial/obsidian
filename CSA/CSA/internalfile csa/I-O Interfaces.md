# I/O Interfaces

## Definition

An I/O interface is hardware that connects peripheral devices to CPU and memory.

## Need

I/O devices have different speeds and formats, so interface circuits are required.

## Functions

- Data buffering
- Status checking
- Control signal generation
- Data format conversion
- Address decoding

## Exam Answer

I/O interface acts as a bridge between CPU and peripheral devices. It handles data transfer, status signals, and control operations.
