# Auxiliary Memory

## Definition

Auxiliary memory is secondary storage used for permanent storage of data and programs.

## Examples

- Hard disk
- SSD
- Pen drive
- CD/DVD
- Magnetic tape

## Features

- Non-volatile.
- Large capacity.
- Cheaper than main memory.
- Slower than main memory.

## Exam Answer

Auxiliary memory provides permanent storage. It is not directly accessed by CPU and is slower but larger and cheaper than primary memory.
