# Cache Memory

## Definition

Cache memory is a small high-speed memory placed between CPU and main memory.

## Purpose

It stores frequently used data and instructions to reduce average memory access time.

## Terms

| Term | Meaning |
|---|---|
| Hit | Data found in cache |
| Miss | Data not found in cache |
| Hit ratio | Fraction of accesses found in cache |
| Miss ratio | 1 - hit ratio |

## Formula

```text
AMAT = Hit ratio x cache time + Miss ratio x miss penalty
```

## Exam Answer

Cache memory increases speed by keeping frequently used data near CPU. It works on temporal and spatial locality.
