# Multi-module Memory

## Definition

Multi-module memory divides main memory into multiple independent modules.

## Need

It allows parallel access and increases memory bandwidth.

## Example

```text
Module 0: addresses 0,4,8
Module 1: addresses 1,5,9
Module 2: addresses 2,6,10
Module 3: addresses 3,7,11
```

## Exam Answer

Multi-module memory improves speed by allowing several memory modules to operate independently. It is commonly used with interleaving.
