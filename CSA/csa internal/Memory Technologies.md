# Memory Technologies

## Meaning

Memory technologies are hardware technologies used to store data in computer systems.

## Types

| Technology | Example |
|---|---|
| Semiconductor memory | RAM, ROM, cache |
| Magnetic memory | Hard disk, magnetic tape |
| Optical memory | CD, DVD |
| Flash memory | SSD, pen drive |

## Exam Answer

Different memory technologies are used based on speed, cost, and capacity. Semiconductor memory is fast, magnetic memory is large and cheap, optical memory is removable, and flash memory is non-volatile and fast.
