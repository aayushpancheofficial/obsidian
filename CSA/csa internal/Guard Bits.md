# Guard Bits

## Definition

Guard bits are extra bits used during floating point arithmetic to improve accuracy.

## Need

During shifting and rounding, some bits may be lost. Guard bits preserve extra precision before final rounding.

## Use

- Floating point addition
- Floating point subtraction
- Rounding operations

## Exam Answer

Guard bits are temporary extra bits used to reduce rounding error in floating point arithmetic. They improve precision before the final result is rounded.
