# Functional Units of a Computer

## Definition

Functional units are the main parts of a computer system that work together to process data and execute instructions.

## Main Units

| Unit | Function |
|---|---|
| Input Unit | Accepts data and instructions |
| Memory Unit | Stores data, instructions, and results |
| ALU | Performs arithmetic and logic operations |
| Control Unit | Controls and coordinates all operations |
| Output Unit | Displays final result |
| Registers | High-speed temporary storage inside CPU |

## Diagram

```text
Input Unit -> Memory Unit <-> CPU <-> Output Unit
                         CPU = ALU + Control Unit + Registers
```

## Exam Answer

A computer system consists of input unit, memory unit, arithmetic logic unit, control unit, registers, and output unit. Input unit accepts data, memory stores data and instructions, ALU performs arithmetic and logical operations, control unit generates control signals, registers store temporary data, and output unit displays results.

## Remember

Input gives data, memory stores it, CPU processes it, output shows result.
