# Parameter Passing

## Definition

Parameter passing is the method used to send values from a calling program to a subroutine.

## Methods

| Method | Meaning |
|---|---|
| Register method | Parameters passed through CPU registers |
| Memory method | Parameters stored in memory locations |
| Stack method | Parameters pushed onto stack |
| Call by value | Copy of value is passed |
| Call by reference | Address of variable is passed |

## Subroutine

A subroutine is a small program module called by the main program to perform a specific task.

## Exam Answer

Parameter passing allows a main program to provide data to a subroutine. Parameters may be passed through registers, memory, or stack. Stack-based parameter passing is flexible and commonly used for nested subroutine calls.
