# Signed Multiplication

## Meaning

Signed multiplication multiplies positive and negative binary numbers.

## Methods

- Sign magnitude multiplication
- 2's complement multiplication
- Booth's algorithm
- Modified Booth / bit-pair recoding

## Important Point

Booth's algorithm is commonly used for signed 2's complement multiplication.

## Exam Answer

Signed multiplication must handle sign bits correctly. Booth's algorithm is efficient for signed 2's complement numbers because it uses add, subtract, and arithmetic right shift based on multiplier bit pairs.
