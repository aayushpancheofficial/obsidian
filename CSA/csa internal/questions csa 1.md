#### Q. What are Addressing Modes? Explain types.

##### Answer

###### Addressing Modes
Addressing modes are the methods used by a computer to specify the location of an operand (data) in an instruction.

They define how the effective address of the operand is obtained.

---

###### Types of Addressing Modes

###### 1. Immediate Addressing
- Operand is given directly in the instruction  
Example: MOV A, 5  

---

###### 2. Direct Addressing
- Address field contains the actual memory address of operand  
Example: MOV A, [1000]

---

###### 3. Indirect Addressing
- Address field contains address of another location where operand is stored  
Example: MOV A, [[1000]

---

###### 4. Register Addressing
- Operand is stored in register  
Example: MOV A, R1  

---

###### 5. Register Indirect Addressing
- Register contains address of operand  
Example: MOV A, [R1]

---

###### 6. Indexed Addressing
- Effective address = Base address + Index  
Used in arrays  

---

###### 7. Relative Addressing
- Effective address = PC + offset  
Used in branching  

---

###### Conclusion
Addressing modes help in efficient data access and flexible instruction design.


#### Q. Explain Instruction Formats

##### Answer

###### Instruction Format
An instruction format is the structure of a machine instruction that specifies:
- Operation to be performed  
- Location of operands  

It defines how bits of an instruction are organized.

---

###### Basic Components of Instruction

- Opcode: Specifies operation (ADD, SUB, etc.)  
- Operand: Data or address of data  
- Address field: Location of operand  

---

###### Types of Instruction Formats

###### 1. Three-Address Instruction
- Contains 3 operands  

Example:
ADD A, B, C  
(A = B + C)

---

###### 2. Two-Address Instruction
- One operand acts as both source and destination  

Example:
ADD A, B  
(A = A + B)

---

###### 3. One-Address Instruction
- Uses accumulator  

Example:
ADD B  
(A = A + B)

---

###### 4. Zero-Address Instruction
- No explicit operand  
- Used in stack-based systems  

Example:
ADD (top two stack values)

---

###### Other Classification

###### Fixed Length Format
- All instructions have same size  
- Easy to decode  

###### Variable Length Format
- Instructions have different sizes  
- More flexible but complex  

---

###### Conclusion
Instruction formats determine how instructions are stored and executed, affecting performance and efficiency of CPU.

#### Q. Differentiate between Hardwired Control Unit and Microprogrammed Control Unit

##### Answer

###### Hardwired Control Unit vs Microprogrammed Control Unit

1. Implementation
- Hardwired: Uses combinational circuits (gates, flip-flops)  
- Microprogrammed: Uses control memory (microinstructions)

---

2. Speed
- Hardwired: Faster  
- Microprogrammed: Slower (due to memory access)

---

3. Flexibility
- Hardwired: Less flexible (difficult to modify)  
- Microprogrammed: More flexible (easy to modify)

---

4. Complexity
- Hardwired: Complex design for large instruction sets  
- Microprogrammed: Simpler design

---

5. Control Signals
- Hardwired: Generated directly by hardware  
- Microprogrammed: Generated by microprogram

---

6. Cost
- Hardwired: Cheaper for simple systems  
- Microprogrammed: Costly due to control memory

---

7. Suitability
- Hardwired: RISC architecture  
- Microprogrammed: CISC architecture

---

###### Conclusion
Hardwired control unit is faster but less flexible, while microprogrammed control unit is slower but easier to design and modify.

#### Q. Explain Accumulator-Based CPU with diagram

##### Answer

###### Accumulator-Based CPU
An accumulator-based CPU is a type of processor in which one special register called the accumulator (AC) is used for all arithmetic and logical operations.

All intermediate results are stored in the accumulator.

---

###### Block Diagram (Text Representation)

          +------------------+
          |   Memory Unit    |
          +------------------+
                   |
                   |
          +------------------+
          |  Control Unit    |
          +------------------+
                   |
                   |
          +------------------+
          | Arithmetic Logic |
          |      Unit (ALU)  |
          +------------------+
                   |
                   |
          +------------------+
          |  Accumulator (AC)|
          +------------------+

---

###### Working

1. Data is fetched from memory to accumulator  
2. ALU performs operation using accumulator  
3. Result is stored back in accumulator  
4. Final result may be stored in memory  

---

###### Example

Instruction: ADD X  

AC = AC + M[X]  

---

###### Features

- Uses single register (AC) for operations  
- Simple instruction format  
- Requires more memory accesses  

---

###### Conclusion

Accumulator-based CPU is simple in design but slower due to frequent memory usage.
