# Memory Management Hardware

## Meaning

Memory management hardware supports address translation, protection, and efficient memory use.

## Components

- MMU
- Page table register
- TLB
- Base and limit registers
- Protection bits

## MMU

Memory Management Unit translates logical/virtual addresses into physical addresses.

## Exam Answer

Memory management hardware provides address translation and protection. MMU, page tables, TLB, and protection bits help manage memory efficiently.
