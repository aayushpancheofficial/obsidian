# Control Signal Sequencing

## Meaning

Control signal sequencing is the proper timing and ordering of control signals required to execute an instruction.

## Need

Each instruction requires a sequence of micro-operations. Control signals activate registers, ALU, memory, and buses in the correct order.

## Example

Fetch sequence:

```text
T0: MAR <- PC
T1: MDR <- M[MAR], PC <- PC + 1
T2: IR <- MDR
```

## Exam Answer

Control signal sequencing ensures that micro-operations occur in correct time steps. It is generated by the control unit and is essential for proper instruction execution.
