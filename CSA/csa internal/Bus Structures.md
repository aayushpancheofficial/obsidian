# Bus Structures

## Definition

A bus is a common communication path used to transfer data, addresses, and control signals between computer units.

## Types of Bus

| Bus | Function |
|---|---|
| Data Bus | Transfers actual data |
| Address Bus | Carries memory or I/O address |
| Control Bus | Carries read, write, interrupt, and clock signals |

## Diagram

```text
CPU <==== System Bus ====> Memory
  \                       /
   \==== I/O Devices ==== 

System Bus = Data Bus + Address Bus + Control Bus
```

## Exam Answer

Bus structure connects CPU, memory, and I/O devices. The data bus transfers data, address bus carries address, and control bus carries control signals. Bus architecture reduces wiring and provides a common path for communication.
