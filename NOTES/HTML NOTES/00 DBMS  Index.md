# DBMS Exam Index

Kal ke exam ke liye priority: pehle repeated PYQ, phir diagrams, phir examples. Har answer ko 8 marks me likhne ka formula:

1. Definition
2. Diagram, agar topic me possible ho
3. Main points / types / components
4. Example
5. Advantages / conclusion
