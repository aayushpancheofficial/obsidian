# JavaScript Fundamentals - deepseek

> A beginner's guide to JS: setup, variables, data types, and best practices.

## 1. Introduction to JavaScript

- **What is it?**  
  A popular programming language for web (frontend) and backend (Node.js).

- **Purpose**  
  Give instructions to computers:  
  `Input (code) → Output (result / website)`

- **No prerequisites** – learn from zero.

- **Approach**  
  Theory + Practice + Real‑world projects.

---

## 2. Environment Setup

### Run JS anywhere

| Method | How | Best for |
|--------|-----|-----------|
| **Browser Console** | `F12` → Console tab<br>`Ctrl+K` (clear) | Quick tests |
| **VS Code + HTML** | `index.html` linking `.js` file | Real projects |

### Connect JS to HTML

1. Create folder → `first.js` + `index.html`
2. In `index.html` (shortcut: `!` + `Enter`):
   ```html
   <body>
     <script src="first.js"></script>
   </body>
   ```
3. Open `index.html` → see output in **Console**.

### First code examples

```javascript
alert("My College");       // pop‑up
console.log("My College"); // to console
// use ; at end (good practice)
// strings: '' or "" both fine
```

## 3. Variables

> Containers for storing data.  
> **Analogy:** labelled boxes – name is the label, value is what’s inside.

- **Dynamic typing** – JS auto‑detects type (a variable can change type over time).
- **Assignment operator** = puts the right value into the left variable.

### Declaration keywords

| Keyword | Modern? | Re‑declare? | Update value? | Scope |
|---------|---------|-------------|---------------|-------|
| `var`   | ❌ Old  | Yes         | Yes           | Global/Function |
| `let`   | ✅ Yes  | No          | Yes           | Block |
| `const` | ✅ Yes  | No          | **No** (immutable reference) | Block |

> **Best practice:**  
> - Default to `const` – if value shouldn’t change.  
> - Use `let` when you need to reassign.  
> - Avoid `var` (bugs, confusion).

📌 `const` with objects:  
You cannot reassign the whole object, **but you can modify its properties**.

### Naming rules

1. **Case‑sensitive** – `age` ≠ `Age`
2. Allowed: letters, digits, `_`, `$`  
   - No spaces  
   - No starting digit (`1age` ❌)
3. No reserved keywords (`let`, `const`, `if`, `console`…)
4. **CamelCase** convention:  
   `fullName`, `totalPrice`, `isFollow`  
   (avoid `full_name` or `FullName` for variables)

### Scope (preview)

- `let` / `const` → **block scope** `{ ... }`
- `var` → global / function scope

## 4. Data Types

### A. Primitive (7 types)

| Type      | Example             | Notes                     |
| --------- | ------------------- | ------------------------- |
| Number    | `24`, `99.99`, `-5` | integers & floats         |
| String    | `"Tony Stark"`      | quotes required           |
| Boolean   | `true` / `false`    |                           |
| Undefined | `let x;`            | declared but not assigned |
| Null      | `let y = null;`     | intentional absence       |
| BigInt    | `123n`              | very large integers       |
| Symbol    | `Symbol("id")`      | unique identifiers        |

> ⚠️ `typeof null` returns `"object"` – a historical JS bug.

### B. Non‑primitive – Object

Collection of key‑value pairs (like a student record).

```javascript
const student = {
    fullName: "Rahul Kumar",
    age: 20,
    cgpa: 8.2,
    isPass: true
};
```

#### Access values

```javascript
student.age;        // dot notation → 20
student["age"];     // bracket notation → 20
```

#### Modify (even with `const`)

```javascript
student.age = 21;
student.fullName = "Rahul Sharma";
```

### Check data type – `typeof`

```javascript
let age = 24;
console.log(typeof age);    // "number"

let name = "Tony";
console.log(typeof name);   // "string"

let isFollow = true;
console.log(typeof isFollow); // "boolean"
```

## ✅ Key Takeaways for Beginners

- **Start simple** – browser console for quick experiments, VS Code for real work.
- **Extensions matter** – `.js` for JavaScript, `.html` for web pages.
- **Naming** – use meaningful **camelCase** (`userAge` not `x`).
- **Safety** – prefer `const`. Use `let` only when you must reassign.
- **Objects** – think of them as “bundles” of data (like a profile card), not single values.
