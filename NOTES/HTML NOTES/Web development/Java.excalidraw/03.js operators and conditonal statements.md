#### 1. Introduction to Comments

Comments are parts of code that are **not executed**. They are used to explain logic.

##### Single Line Comment

```javascript
// This is a single line comment
console.log("Hello"); // comment after code
```

##### Multi-line Comment

```javascript
/* This is a
   multi-line comment */
```

###### Note

- Prefer writing comments in **English** (global standard)

#### 2. Operators

Operators perform operations on values (operands).

---

#### A. Arithmetic Operators

Used for mathematical calculations.

| Operator       | Symbol | Description       | Example (`a = 5`, `b = 2`) |
| -------------- | ------ | ----------------- | -------------------------- |
| Addition       | `+`    | Adds values       | `a + b = 7`                |
| Subtraction    | `-`    | Subtracts values  | `a - b = 3`                |
| Multiplication | `*`    | Multiplies values | `a * b = 10`               |
| Division       | `/`    | Divides values    | `a / b = 2.5`              |
| Modulus        | `%`    | Returns remainder | `a % b = 1`                |
| Exponentiation | `**`   | Power             | `a ** b = 25`              |

---

#### Unary Operators

Work on a **single operand**

##### Increment (`++`)

- Increase value by 1
    

##### Decrement (`--`)

- Decrease value by 1
    

---

#### Pre vs Post Increment

##### Pre → `++a`

- Pehle increase hota hai, phir use hota hai
    

##### Post → `a++`

- Pehle use hota hai, phir increase hota hai
    

---

#### Example

```javascript
let a = 5;

console.log(++a); // 6
console.log(a++); // 6 (then becomes 7)
console.log(a);   // 7
```

---

#### B. Assignment Operators

Used to assign values.

|Operator|Meaning|
|---|---|
|`=`|Assign value|
|`+=`|Add and assign|
|`-=`|Subtract and assign|
|`*=`|Multiply and assign|
|`/=`|Divide and assign|
|`%=`|Modulus and assign|
|`**=`|Power and assign|

##### Example

```javascript
let a = 5;
a += 4; // 9
a *= 2; // 18
```

---

#### C. Comparison Operators

Return **true or false**

| Operator | Meaning            | Example             |
| -------- | ------------------ | ------------------- |
| ==       | Equal (value only) | `5 == "5"` → true   |
| ===      | Strict Equal       | `5 === "5"` → false |
| `!=`     | Not equal          |                     |
| `!==`    | Strict not equal   |                     |
| `>`      | Greater than       |                     |
| `<`      | Less than          |                     |
| `>=`     | Greater or equal   |                     |
| `<=`     | Less or equal      |                     |

###### Important

- Always prefer **=== (strict equality)**
    

---

#### D. Logical Operators

| Operator | Meaning         |
| -------- | --------------- |
| `&&`     | AND (both true) |
| \|\|     | OR              |
| `!`      | NOT (reverse)   |

##### Example

```javascript
true && false // false
true || false // true
!true         // false
```

#### 3. Conditional Statements
#### A. if Statement

```javascript
let age = 25;

if (age >= 18) {
    console.log("You can vote");
}
```

---

#### B. if...else

```javascript
let age = 16;

if (age >= 18) {
    console.log("Can vote");
} else {
    console.log("Cannot vote");
}
```

---

#### C. if...else if...else

```javascript
let score = 75;
let grade;

if (score >= 90 && score <= 100) {
    grade = "A";
} else if (score >= 70 && score <= 89) {
    grade = "B";
} else if (score >= 60 && score <= 69) {
    grade = "C";
} else {
    grade = "F";
}
```

---

#### D. Ternary Operator

Short form of if-else

```javascript
let age = 20;
let status = (age >= 18) ? "Adult" : "Not Adult";
```

---

#### E. switch Statement

- Used for multiple fixed values
    
- Requires `break`
    

---

#### 4. User Input

##### alert()

- Shows popup message
    

##### prompt()

- Takes input (as string)
    

```javascript
let num = prompt("Enter a number");

if (num % 5 === 0) {
    console.log("Multiple of 5");
}
```

num % 5 === 0
