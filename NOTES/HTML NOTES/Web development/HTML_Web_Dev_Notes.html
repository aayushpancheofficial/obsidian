What is HTML?

01
Definition

HTML = HyperText Markup Language. It is the skeleton of every webpage — it tells the browser what content exists and what it means (not how it looks).

The 3 Languages of the Web

HTML → Structure  |  CSS → Style  |  JavaScript → Behaviour

HTML = bones CSS = skin JS = muscles
💡 HTML files are just plain text files saved with a .html extension. You can open one with any browser.
🏗️

Basic Page Structure

02
Anatomy of an HTML Tag

Tags wrap content. Most tags have an opening and a closing tag.

html 
<!-- Opening tag  content  Closing tag -->
<p>   Hello World   </p>

<!-- Self-closing (void) tag – no content -->
<img src="photo.jpg" alt="A photo">
The Full Boilerplate

Every HTML file should start with this template:

html 
<!-- Tells the browser: "this is HTML5" -->
<!DOCTYPE html>

<html lang="en">

  <head>
    <!-- Invisible metadata -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page</title>
    <link rel="stylesheet" href="style.css">
  </head>

  <body>
    <!-- Everything VISIBLE goes here -->
    <h1>Hello, World!</h1>
    <script src="script.js"></script>
  </body>

</html>
✅ Tip: In VS Code, type ! then press Tab — it auto-generates the full boilerplate for you!

Text & Headings

03
html 
<!-- Headings: h1 = biggest, h6 = smallest -->
<h1>Main Title</h1>
<h2>Section Title</h2>
<h3>Sub-section</h3>

<!-- Paragraph -->
<p>This is a paragraph of text.</p>

<!-- Inline formatting -->
<strong>Bold / important</strong>

⚠️ Use only one <h1> per page — it's your main heading and important for SEO.

Links & Images

04
html — links 
<!-- External link -->
<a href="https://google.com" target="_blank">Google</a>

<!-- Link to another page in your site -->
<a href="about.html">About Me</a>

<!-- Jump to a section on the same page -->
<a href="#contact">Go to Contact</a>
<section id="contact">...</section>

<!-- Email link -->
<a href="mailto:hello@email.com">Email me</a>
html — images 
<!-- Basic image -->
<img src="cat.jpg" alt="A cute cat" width="300">

<!-- Image from the web -->
<img src="https://example.com/photo.jpg" alt="Description">

<!-- Clickable image (link + image combined) -->
<a href="https://google.com">
  <img src="logo.png" alt="Google Logo">
</a>

width / heightSet size in pixelsOptional
loading="lazy"Delays loading until image is in view (performance)Optional

Semantic HTML

08
What is Semantic HTML?

Using tags that describe the meaning of content, not just its appearance. Helps SEO, accessibility, and code readability.

html — semantic layout 
<header>   <!-- Site logo, nav, title -->
  <nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
  </nav>
</header>

<main>     <!-- Primary page content -->
  <article>  <!-- Self-contained content (blog post, etc.) -->
    <h1>My Blog Post</h1>
    <p>Content here...</p>
  </article>

  <aside>    <!-- Sidebar or related content -->
    <p>Related links</p>
  </aside>
</main>

<footer>   <!-- Copyright, links -->
  <p>© 2025 My Site</p>
</footer>
💡 Use <div> only for layout/styling with no specific meaning. Use semantic tags everywhere else.

CSS Basics

09
3 Ways to Add CSS

Inline (bad practice) → Internal <style> tag → External .css file (best)

css — syntax 
/* selector { property: value; } */

h1 {
  color: navy;
  font-size: 2rem;
  text-align: center;
}

/* Class selector */
.card {
  background: #f0f0f0;
  padding: 1rem;
  border-radius: 8px;
}

/* ID selector */
#hero {
  height: 100vh;
  background: linear-gradient(135deg, #667eea, #764ba2);
}

/* Pseudo-class (hover state) */
a:hover {
  color: red;
  text-decoration: underline;
}
css — flexbox quick layout 
.container {
  display: flex;
  justify-content: center;   /* horizontal */
  align-items: center;      /* vertical */
  gap: 1rem;                 /* space between items */
  flex-wrap: wrap;           /* wrap to next line */
}

JavaScript Basics

10
javascript — DOM manipulation 
// Select an element
const btn = document.querySelector("#myButton");
const all = document.querySelectorAll(".card");

// Change content
btn.textContent = "Click me!";
btn.style.color = "red";

// Add class
btn.classList.add("active");
btn.classList.toggle("hidden");

// Listen for events
btn.addEventListener("click", function() {
  alert("Button clicked!");
});

// Create and add a new element
const p = document.createElement("p");
p.textContent = "Hello!";
document.body.appendChild(p);

The CSS Box Model

11
Every element is a box with 4 layers

Content → Padding → Border → Margin (outside in)

css 
.box {
  width: 200px;          /* content width */
  padding: 20px;         /* space INSIDE border */
  border: 2px solid #333; /* the border line */
  margin: 10px;          /* space OUTSIDE border */

  /* Make sizing predictable — always add this! */
  box-sizing: border-box;
}
✅ Add *, *::before, *::after { box-sizing: border-box; } at the top of every CSS file. It prevents surprise size overflows.
