#### What is HTML?

##### Definition

**HTML stands for HyperText Markup Language.**

HTML is the standard language used to create the structure of webpages.

In simple words, **HTML is the skeleton of a website**.

---

#### Simple Explanation

A website mainly has three parts:

|Technology|Work|
|---|---|
|HTML|Structure|
|CSS|Design|
|JavaScript|Logic/Interaction|

Example:

- **HTML** creates button, heading, paragraph, image.
    
- **CSS** makes them beautiful.
    
- **JavaScript** makes them interactive.
    

---

#### Real-Life Example

Think of a house:

|Website Part|House Example|
|---|---|
|HTML|Walls, rooms, doors|
|CSS|Paint, decoration|
|JavaScript|Electricity, switches|

So, HTML creates the basic structure of the webpage.

---

#### Example of HTML Code

```html
<!DOCTYPE html>
<html>
<head>
  <title>My First Page</title>
</head>
<body>

  <h1>Hello Aayush</h1>
  <p>This is my first webpage.</p>

</body>
</html>
```

---

#### Explanation of Code

|Code|Meaning|
|---|---|
|`<!DOCTYPE html>`|Tells browser this is an HTML5 document|
|`<html>`|Root element of the webpage|
|`<head>`|Contains page information|
|`<title>`|Title shown on browser tab|
|`<body>`|Visible content of webpage|
|`<h1>`|Main heading|
|`<p>`|Paragraph|

---

#### Why HTML is Used?

HTML is used to create:

- Headings
    
- Paragraphs
    
- Images
    
- Links
    
- Buttons
    
- Lists
    
- Tables
    
- Forms
    
- Videos
    
- Webpage layout
    

---

#### Common HTML Tags

```html
<h1>Heading</h1>
<p>Paragraph</p>
<a href="https://google.com">Link</a>
<img src="image.jpg" alt="Image">
<button>Click Me</button>
```

---

#### Important Point

HTML is **not a programming language**.  
It is a **markup language**.

##### Why?

Because HTML does not use logic like loops, conditions, or calculations.  
It only marks and structures content.

---

#### One-Line Answer for Exam
